# FixItNow — production-ready Gemini repair assistant

FixItNow is a full-stack household repair assistant with authentication, persistent diagnosis history, image uploads, and optional Gemini multimodal diagnosis.

## Local setup

Requirements: Node.js 20+

```bash
npm ci
cp .env.example .env
```

Set `GEMINI_API_KEY` and a strong `JWT_SECRET` in `.env`, then:

```bash
npm start
```

Open `http://localhost:3000`.

Health check: `http://localhost:3000/health`

## Production deployment — Render

This repo includes `render.yaml`.

1. Push the project to GitHub.
2. In Render, create a new Blueprint and select the repository.
3. Render will use the included Node build/start commands and create a persistent disk at `/var/data`.
4. Set the secret `GEMINI_API_KEY` in Render's environment settings.
5. `JWT_SECRET` is generated by Render.
6. Deploy and use the generated HTTPS URL.

The persistent disk keeps SQLite and uploaded images across deploys/restarts. For horizontal scaling or a high-traffic public product, move the database to PostgreSQL and images to object storage.

## Docker

```bash
docker build -t fixitnow .
docker run --rm -p 3000:3000 --env-file .env -v "$PWD/data:/app/data" fixitnow
```

## AI flow

Browser → `/api/diagnose` → server → Gemini → structured JSON → SQLite → browser.

The Gemini API key is never sent to browser JavaScript. If Gemini is unavailable, FixItNow falls back to built-in safety-first rules.

## Safety

The AI is intentionally conservative. It should not instruct users to open live electrical wiring, gas systems, sealed refrigerant systems, damaged batteries, or other hazardous internals.
